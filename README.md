# Randomix

Aplicación web para realizar selecciones aleatorias de estudiantes a partir de archivos Excel.

## Objetivo

Importar y validar listados de estudiantes, seleccionar registros aleatoriamente sin reemplazo y generar archivos Excel y PDF con los resultados.

## Funcionalidades previstas

- Acceso administrativo.
- Importación de archivos XLS y XLSX.
- Selección de hoja de cálculo.
- Validación de encabezados y registros.
- Selección aleatoria sin reemplazo.
- Exportación de seleccionados y registros restantes a Excel y PDF.
- Eliminación automática de archivos temporales y resultados vencidos.

## Entorno de desarrollo

- PHP.
- Apache.
- MariaDB/MySQL.
- Composer.

## Instalación

Las instrucciones de instalación se documentarán cuando se definan las dependencias y la configuración definitiva del proyecto.

## Seguridad

No subir archivos con información personal de estudiantes, contraseñas, archivos `.env` reales ni resultados de selecciones.
